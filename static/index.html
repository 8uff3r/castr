Recommended Setup (OBS Studio / FFmpeg)

  1. In OBS Studio, go to Settings → Stream.
  2. Set Service to Custom.
  3. Paste the Server URL (`rtmp://localhost:1935/live`) and your chosen Stream Key (`my_webcam`).
  4. Click Start Streaming in OBS or run: 
    ffmpeg -re -i input.mp4 -c:v libx264 -f flv rtmp://localhost:1935/live/my_webcam
  5. Your high-definition stream will instantly appear on the Castr Live directory for all registered viewers!
